# جِسر (Jisr) — منصة تعلم اللغة الصينية HSK 1

منصة تفاعلية كاملة لتعلم اللغة الصينية (المستوى الأول HSK 1) مصممة خصيصاً للناطقين بالعربية.
واجهة عربية RTL بالكامل، وضع داكن افتراضي، وتحفظ تقدمك في المتصفح.

**桥 — الجسر بين العربية والصينية**

## الأقسام (19 قسماً)

- **لوحة التحكم** — تقدمك، هدفك اليومي، كلماتك الضعيفة
- **المفردات** — 411 كلمة HSK 1 مع بطاقات ذكية ونظام مراجعة متباعدة (SM-2 SRS)
- **الدروس** — 15 درساً تفاعلياً
- **القواعد** — 27 قاعدة نحوية بأمثلة وتمارين
- **البينيين** — النبرات والمقاطع الصوتية
- **الحروف** — تعلم كتابة الحروف بالترتيب الصحيح (HanziWriter)
- **المحادثات، الجمل، القصص، القاموس البصري**
- **التمارين والألعاب** — اختبارات، لعبة الذاكرة، تمييز النبرات
- **محاكي الامتحان** — امتحان HSK 1 كامل (40 سؤالاً)
- **المعلم الذكي** — مساعد يجيب من بيانات المنصة: شرح كلمات وقواعد، اختبارات مخصصة من نقاط ضعفك، وخطط مراجعة — بدون أي API خارجي
- **الإعدادات** — الثيم، حجم الحروف الصينية، الصوت والسرعة، الهدف اليومي، تصدير/استيراد التقدم

## التقنيات

- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS 4 + shadcn/ui
- Zustand (حفظ التقدم في المتصفح localStorage)
- Web Speech API للنطق

## التشغيل محلياً

```bash
npm install
npm run dev
# افتح http://localhost:3000
```

## البناء والنشر

```bash
npm run build
npm start
```

المشروع جاهز للنشر على Vercel مباشرة (لا يحتاج متغيرات بيئة أو قاعدة بيانات).

## ملاحظات مهمة

- **التقدم والملف الشخصي محفوظان على الجهاز فقط** (localStorage). استخدم "تصدير التقدم" من الإعدادات كنسخة احتياطية أو للنقل بين الأجهزة.
- **الترخيص لكل جهاز**: التفعيل عبر `/api/validate-license`. للإنتاج فعّل تكامل Gumroad الجاهز في الملف (المفاتيح التجريبية: `JISR-TEST-KEY-0001`).
- حسابات متعددة الأجهزة تتطلب قاعدة بيانات مستضافة (Turso/Neon/Supabase) — خارج نطاق النسخة الحالية.
