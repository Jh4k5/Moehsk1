# design/

ملفات مصدر لوحة التصميم — خمس واجهات لمنصة «جسر إلى الصين».

| الملف | الواجهة |
|---|---|
| `Landing.dc.html` | الصفحة التعريفية |
| `Main.dc.html` | الرئيسية (لوحة المتعلّم) |
| `Path.dc.html` | المسار التعليمي مع الإقفال المتدرّج |
| `Unit.dc.html` | صفحة الوحدة وخطة أنشطتها |
| `Activity.dc.html` | شاشة النشاط (مقاس جوال) |
| `canvas.json` | ترتيب اللوح والملاحظات |

الألوان والخطوط والزوايا مأخوذة من رموز `src/app/globals.css` — أي تغيير في الهوية
يُعكَس هنا يدوياً حتى تبقى اللوحة مطابقة لما تعرضه المنصة فعلاً.

المحتوى حقيقي من `src/data`: الدرس الثالث «我是中国人» وكلماته، وتفكيك `好` إلى
`女` و`子`، والكلمات الضعيفة `谢谢` و`老师` و`同学`.

الملف المنشور يُجمَّع من هذه المصادر ولا يُحفظ في المستودع (انظر `.gitignore`).
