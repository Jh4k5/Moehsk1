**1. المساعد الذكي (AI Chatbot)**
- يستخدم GLM-5 Turbo بدون system prompt محكم
- لا يوجد context ثابت يعرّفه كـ"مدرس صيني"
- يخرج عن الموضوع ويولّد أسئلة غير منطقية
- لا يدعم التصحيح الصوتي أو النحوي للمتعلم

**2. الألعاب**
- منطق بدائي (random بدون spaced repetition)
- لا يوجد timer
- لا يوجد صعوبة متدرجة
- الكلمات المحفوظة تتكرر في الألعاب

**3. بنية البيانات**
- الكلمات مصنفة فقط بـ 8 فئات نحوية
- لا يوجد تصنيف حسب الدروس (15 درس منهجي)
- لا يوجد metadata للصعوبة، الاستخدام، السياق

**4. تعلم الرموز (Hanzi)**
- العرض فقط — لا يوجد stroke order
- لا يوجد تدريب على الكتابة
- لا يوجد ربط بين البنية البصرية للرمز ومعناه
- لا يوجد radical decomposition (تشريح مكونات الرمز)

**5. البينيين (Pinyin)**
- يُعرض كـ label فقط تحت الرمز
- لا يوجد قسم منهجي مستقل للبينيين
- لا يشرح نظام النبرات الأربعة بشكل تفاعلي
- لا يوجد تمييز بصري للنبرة داخل الكلمة

**6. التقييم الصوتي**
- موجود Web Speech API للاستماع فقط
- لا يوجد تسجيل + تقييم نطق المستخدم
- لا يوجد مقارنة بين صوت المستخدم والنطق الصحيح

**7. اختبارات HSK**
- غائبة كلياً
- HSK 1 لديه نوعان: الاستماع (35 سؤال) والقراءة (20 سؤال)
- لا يوجد توقيت حقيقي، لا محاكاة فعلية

## ثالثاً: الأقسام الجديدة المطلوبة بتفصيل كامل

### قسم 1: مركز البينيين (Pinyin Hub)
**الهدف:** تأسيس كامل لنظام الأصوات الصينية قبل أي كلمة

**المكونات:**
- جدول تفاعلي كامل لـ Initials (21 حرف ابتدائي) + Finals (39 صوت نهائي)
- كل خانة في الجدول قابلة للنقر → تشغيل الصوت
- شرح النبرات الأربعة + النبرة المحايدة (5 نبرات) بـ animation يوضح منحنى الصوت
- مقارنة مرئية بين أصوات مشابهة في العربية وأصوات غير موجودة (مثل: zh, ch, sh, x, q)
- تمرين: استمع واختر النبرة الصحيحة من 4 خيارات
- تمرين: اكتب البينيين الذي سمعته (text input)
- جدول مراجعة: كل صوت + مثال كلمة + نطق

**التقنية المطلوبة:**
- Web Speech API (موجود) لتشغيل الأصوات
- CSS animation لمنحنى النبرة (SVG path animation)
- لا API خارجي مطلوب للجزء الأساسي

### قسم 2: تعلم الرموز (Hanzi Mastery)
**الهدف:** تحويل الرمز من صورة مجهولة إلى وحدة محفوظة في الذاكرة

**المكونات:**

**أ. Stroke Order Viewer**
- مكتبة Hanzi Writer (مفتوحة المصدر، MIT License)
- تحميل: `npm install hanzi-writer` أو CDN
- يعرض كل رمز خطوة بخطوة مع animation
- زر "play" لمشاهدة الرسم الكامل
- زر "step" للتقدم خطوة بخطوة

**ب. Stroke Practice Canvas**
- Canvas HTML5 يسمح للمستخدم برسم الرمز بالإصبع (touch) أو الماوس
- Hanzi Writer يدعم نمط "quiz mode" تلقائياً
- النظام يتحقق من صحة كل خطوة ويعطي تغذية راجعة فورية
- مقياس دقة من 0-100% لكل رمز

**ج. تشريح الرمز (Radical Decomposition)**
- كل رمز يُشرح من خلال مكوناته:
  - مثال: 好 = 女 (امرأة) + 子 (طفل) = جيد (لأن الأم والطفل معاً = سعادة)
- هذا الربط القصصي يرفع معدل الحفظ بنسبة 40-60% (بحسب دراسات Spaced Repetition)
- قاعدة بيانات من أهم 50 radical في HSK 1

**د. Mnemonics Generator**
- نص قصير (جملة أو صورة ذهنية) لكل رمز باللغة العربية
- يمكن للمستخدم تعديله وكتابة mnemonic خاص به

**التقنية:**
```html
<script src="https://cdn.jsdelivr.net/npm/hanzi-writer@3.5/dist/hanzi-writer.min.js"></script>
```
```javascript
const writer = HanziWriter.create('character-target-div', '好', {
  width: 250,
  height: 250,
  padding: 5,
  showOutline: true,
  strokeAnimationSpeed: 1,
  delayBetweenStrokes: 300,
});

// Quiz mode (المستخدم يرسم)
writer.quiz({
  onMistake: (strokeData) => { /* تغذية راجعة */ },
  onCorrectStroke: (strokeData) => { /* تأكيد */ },
  onComplete: (summaryData) => { /* النتيجة */ }
});
```

### قسم 4: المحادثات التفاعلية (Conversation Practice)
**الهدف:** الانتقال من حفظ كلمات إلى استخدامها في سياق حقيقي

**المكونات:**

**أ. عرض المحادثة**
- واجهة فقاعات محادثة (Chat Bubbles)
- كل فقاعة: Hanzi + Pinyin + عربي + زر صوت
- زر "إخفاء الترجمة" للتحدي

**ب. تمرين تكمل الجملة (Fill Role)**
- الشخصية A محجوبة والمستخدم يكمل دورها
- 3 خيارات للاختيار (MCQ) أو كتابة حرة
- بعد الإجابة: مقارنة فورية مع الجواب الصحيح

**ج. تسجيل المحادثة (Voice Role-Play)**
- يضغط المستخدم "سجل دوري"
- يقرأ الجملة المطلوبة
- النظام يحلل النطق (Web Speech API → نص)
- مقارنة النص المُنتج بالجواب الصحيح (string similarity ≥ 85%)

**الخيار B: Azure Speech API (مدفوع، لكن دقيق جداً)**

- يعطي: نقاط النطق / الطلاقة / الاكتمال / دقة النبرة
- السعر: $1 لكل 10,000 كلمة (رخيص جداً)

**الخيار C: Google Cloud Speech-to-Text (متوسط التكلفة)**

**التوصية:** ابدأ بـ Web Speech API مجاناً مع خوارزمية Levenshtein Distance لمقارنة النصوص، ثم انتقل لـ Azure لاحقاً.

**خوارزمية التقييم:**
```javascript
function scorepronunciation(spoken, expected) {
  const similarity = levenshteinSimilarity(spoken, expected);
  const toneScore = compareTones(spoken, expected);
  const finalScore = (similarity * 0.6) + (toneScore * 0.4);
  
  if (finalScore >= 0.9) return { score: 95, feedback: "ممتاز! النطق دقيق جداً" };
  if (finalScore >= 0.75) return { score: 80, feedback: "جيد جداً، انتبه للنبرة" };
  if (finalScore >= 0.6) return { score: 65, feedback: "جيد، حاول مرة أخرى" };
  return { score: 40, feedback: "تحتاج مراجعة النطق" };
}
```

## رابعاً: نظام التعلم الذكي (Adaptive Learning Engine)

### Spaced Repetition System (SRS)
**الخوارزمية المطلوبة: SM-2 (نفس Anki)**

```javascript
function calculateNextReview(card, quality) {
  // quality: 0-5 (0=فشل تام, 5=مثالي)
  
  if (quality < 3) {
    card.interval = 1;
    card.repetitions = 0;
  } else {
    if (card.repetitions === 0) card.interval = 1;
    else if (card.repetitions === 1) card.interval = 6;
    else card.interval = Math.round(card.interval * card.easeFactor);
    
    card.repetitions++;
    card.easeFactor += 0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02);
    if (card.easeFactor < 1.3) card.easeFactor = 1.3;
  }
  
  card.nextReview = new Date();
  card.nextReview.setDate(card.nextReview.getDate() + card.interval);
  return card;
}
```

**الكلمات المتعلمة لا تتكرر في وضع "تعلم جديد" — تظهر فقط في "مراجعة اليوم".**

- إرسال history كاملة كل طلب (context window)

- وضع "ترجمة + تحليل" — جملة صينية والـ AI يشرح كل كلمة
